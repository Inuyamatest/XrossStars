# クロスファイト ～大乱闘アリーナ～

スマブラ風の 2D 対戦アクションゲーム（PC アプリ / Python + pygame）。
最大4人（人間2人＋CPU）で、%をためてステージの外までふっとばしたら撃墜。

## 遊び方

### Windows（exe）
GitHub の **Actions → 「クロスファイト exe ビルド」** の最新の実行結果から
`CrossFight-windows` をダウンロードし、中の `CrossFight.exe` をダブルクリック。

### Python で起動（Windows / Mac / Linux）
```
cd smash-game
pip install -r requirements.txt
python main.py
```

F11 で全画面、タイトル画面で M を押すと消音。

### アクション
- **弱・強攻撃**: 攻撃（方向なし＝弱3段、左右/上/下＝強攻撃、走りながら＝ダッシュ攻撃）
- **スマッシュ攻撃**: 方向をはじくと同時に攻撃、またはスマッシュボタン。押しっぱなしでため
- **空中攻撃**: 空中で攻撃（ニュートラル・前・後・上・下の5種。下はメテオ）
- **必殺ワザ**: 必殺＋方向で4種類（キャラごとに違う）。上必殺は復帰ワザ（使用後しりもち落下）
- **ガード**: 押している間シールド。攻撃を受けると削れて、割れるとピヨる
- **回避**: ガード中に左右＝ころがり回避、下＝その場回避、空中でガード＝空中回避（方向つき可）
- **つかみ・投げ**: つかみボタン（またはガード中に攻撃）。つかんだら方向で前・後・上・下投げ、攻撃でつかみ打撃。
  ガードはつかみで崩せる。つかまれたらボタン連打で早く抜けられる
- **崖つかまり**: 崖に近づくと自動でつかまる。ステージ側/上で登る、ジャンプ、攻撃、ガードで転がり上がり
- **ずらし**: ふっとばされた瞬間にスティックを倒すと飛ぶ方向を少し変えられる
- **覚醒**: パネル下のゲージ（攻撃を当てる・受けるとたまる）が満タンで攻撃＋必殺同時押し（覚醒ボタン）。
  近くの相手をまとめてふっとばし、10秒間パワーアップ

## モード
- **たいせん**: 2〜4人。ストック数・時間制限・ステージ（戦場 / 終点 / スカイウェイ）・CPUレベル（0〜9）を設定
- **トレーニング**: ストック無限。R でダメージリセット＆覚醒ゲージMAX

## 開発メモ
- `game/world.py` 当たり判定・ふっとばし（スマブラ式の kb 計算）・撃墜・勝敗
- `game/fighter.py` キャラの状態遷移（ガード、回避、つかみ、崖、しりもち…）と物理
- `game/moves.py` / `game/chars.py` ワザとキャラのデータ
- `game/ai.py` CPU（人間と同じ入力を出すだけ）
- `game/render.py` 描画（キャラは画像なしで手続き生成）
- `tests/test_sim.py` CPU同士の全組み合わせを戦わせる自動テスト（`python -m tests.test_sim`）
