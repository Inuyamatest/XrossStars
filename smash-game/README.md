# クロスファイト ～大乱闘アリーナ～

スマブラ風の 2D 対戦アクションゲーム（PC アプリ / Python + pygame）。
最大4人（人間2人＋CPU）で、%をためてステージの外までふっとばしたら撃墜。

## 遊び方

### Windows（exe）
GitHub の **Actions → 「クロスファイト exe ビルド」** の最新の実行結果から
`CrossFight-windows` をダウンロードし、中の `CrossFight.exe` をダブルクリック。

### Python で起動（Windows / Mac / Linux）
```
cd smash-game
pip install -r requirements.txt
python main.py
```

F11 で全画面、タイトル画面で M を押すと消音。

### アクション
- **弱・強攻撃**: 攻撃（方向なし＝弱3段、左右/上/下＝強攻撃、走りながら＝ダッシュ攻撃）
- **スマッシュ攻撃**: 方向をはじくと同時に攻撃、またはスマッシュボタン。押しっぱなしでため
- **空中攻撃**: 空中で攻撃（ニュートラル・前・後・上・下の5種。下はメテオ）
- **必殺ワザ**: 必殺＋方向で4種類（キャラごとに違う）。上必殺は復帰ワザ（使用後しりもち落下）
- **ガード**: 押している間シールド。攻撃を受けると削れて、割れるとピヨる
- **回避**: ガード中に左右＝ころがり回避、下＝その場回避、空中でガード＝空中回避（方向つき可）
- **つかみ・投げ**: つかみボタン（またはガード中に攻撃）。つかんだら方向で前・後・上・下投げ、攻撃でつかみ打撃。
  ガードはつかみで崩せる。つかまれたらボタン連打で早く抜けられる
- **崖つかまり**: 崖に近づくと自動でつかまる（崖下はえぐれているので下からもぐり込んでつかまれる）。ステージ側/上で登る、ジャンプ、攻撃、ガードで転がり上がり
- **受け身**: ふっとばされて床・壁・天井にぶつかる直前（11フレーム以内）にガード。床はその場／左右に転がる受け身、
  壁は張りついて無敵（そのままジャンプで壁ジャンプ）、天井も可。連打は40フレーム受け付けないので狙って押す
- **ずらし**: ふっとばされた瞬間にスティックを倒すと飛ぶ方向を少し変えられる
- **覚醒**: パネル下のゲージ（攻撃を当てる・受けるとたまる）が満タンで攻撃＋必殺同時押し（覚醒ボタン）。
  近くの相手をまとめてふっとばし、10秒間パワーアップ

## キャラを追加する（MUGENキャラ・連番画像）

### MUGEN キャラ
`smash-game/mugen/`（exe の場合は `CrossFight.exe` と同じ場所の `mugen/`）にキャラのフォルダ（`.def` `.sff` `.air` が入っているもの）をそのまま置くと、
キャラ選択に自動で並びます。例: `smash-game/mugen/Taiga/Taiga.def`

- ドット絵（.sff v1/v2）とアニメ、攻撃判定（Clsn1）はキャラのものをそのまま使います
- 標準のアニメ番号（0=立ち、20=歩き、200番台=地上攻撃、600番台=空中攻撃、800=投げ、1000番台=必殺技…）を
  このゲームの弱・強・スマッシュ・空中・必殺ワザに割り当てます
- ダメージやふっとばし、必殺ワザの動き（復帰など）はこのゲーム側の性能を使います（.cns のスクリプトは動かしません）
- 声・効果音（.snd）も鳴ります。.cns の PlaySnd（何番のステートの何フレーム目にどの音）を読んでワザに合わせて再生し、
  やられ声（5000〜5002番）・KO（11番）・勝利（181番）・覚醒（3000番）なども使います

### 連番画像キャラ
`smash-game/charpacks/<名前>/char.json` に「どのモーション画像を何に使うか」を書き、
同じフォルダに画像フォルダを置きます。書き方は `charpacks/donald/char.json` を参照
（画像は `charpacks/donald/ドナルド アニメ(余白無し)/` に置く）。

音を付けるときは char.json に `"sounds"` を書きます（ファイルは char.json からの相対パス、複数書くとランダム）:
```json
"sounds": {"jab": "voice/jab.wav", "fsmash": ["voice/a.wav", "voice/b.wav"],
           "hurt": ["voice/hurt1.wav"], "ko": "voice/ko.wav", "win": "voice/win.wav", "awaken": "voice/awaken.wav"}
```

※ キャラの画像は他の人の著作物のことが多いので、`mugen/` と画像ファイルは git に入らない設定にしています。

## モード
- **たいせん**: 2〜4人。ストック数・時間制限・ステージ（戦場 / 終点 / スカイウェイ）・CPUレベル（0〜9）を設定
- **トレーニング**: ストック無限。R でダメージリセット＆覚醒ゲージMAX

## 開発メモ
- `game/world.py` 当たり判定・ふっとばし（スマブラ式の kb 計算）・撃墜・勝敗
- `game/fighter.py` キャラの状態遷移（ガード、回避、つかみ、崖、しりもち…）と物理
- `game/moves.py` / `game/chars.py` ワザとキャラのデータ
- `game/ai.py` CPU（人間と同じ入力を出すだけ）
- `game/render.py` 描画（キャラは画像なしで手続き生成）
- `tests/test_sim.py` CPU同士の全組み合わせを戦わせる自動テスト（`python -m tests.test_sim`）
